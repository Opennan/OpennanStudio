# @opennan/timeline-media

Thumbnail, waveform, WebCodecs frame decode, and audio-duration helpers for the OpenNan editor timeline. Every network or URL decision goes through a `MediaEnvironment` you pass in.

- `@opennan/timeline-media/dexie`: optional Dexie (IndexedDB) snapshot and sync-queue stores.
- `@opennan/timeline-media/effects`: optional WebGL effect renderer (needs `regl`).
